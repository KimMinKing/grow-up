# 할 일과 정식 전투 연결

할 일 완료로 얻는 기기 훈련권과 첫 숲길 지도는 기기에 저장됩니다. 정식 숲길 전투권·도전 횟수·승리·보상은 계정 서버에 저장됩니다. 두 전투권은 별개입니다.

## 1. 할 일 계정 동기화

[할 일·메모 동기화](DAILY_SYNC_DESIGN.md)는 계정 화면에서 직접 실행합니다. 할 일을 완료한 뒤 **계정 → 할 일·메모 동기화 → 게임 → 정식 파견 → 동기화한 할 일에서 전투권 받기** 순서로 누릅니다. 서버는 완료 여부를 사용자의 자기 보고로 취급합니다. 동기화 충돌이 있으면 유지할 목록을 먼저 선택합니다.

## 2. 서버 전투권 원장

완료 보상의 키는 `계정 + 할 일 ID + 완료 회차 날짜`입니다. 반복 할 일은 날짜별로 한 번씩, 일반 할 일은 완료 날짜 한 번만 보상합니다. 최근 30일의 **별도 할 일** 완료마다 정식 전투권 2장을 받으며 로드맵 연결 행동은 제외합니다. 잔액은 최대 30장입니다. 완료를 취소해도 이미 받은 전투권은 회수하지 않으며 재완료·백업 재가져오기·다른 기기의 청구에도 같은 키로 다시 받지 않습니다.

[`20261107010000_game_task_battle_passes.sql`](../supabase/migrations/20261107010000_game_task_battle_passes.sql)의 지급 원장이 계정별 잠금 아래 중복을 막습니다. 정식 전투 시작은 전투권 1장을 원자적으로 차감합니다. 같은 전투 요청 ID를 재시도하면 다시 차감하지 않습니다. 5분이 지나 만료된 미완료 시도는 새 전투를 시작할 때 전투권을 돌려줍니다. 하루 15회 도전 상한은 유지합니다. 기존 계정에 전환용 전투권 2장을 지급했습니다.

## 3. 지도와 계정 진행 표시

로그인한 사용자의 지도에는 서버 첫 승리와 지급 조각을 계정 기록으로 표시합니다. 기기 별점·칭호는 기기 기록으로 따로 표시합니다. 지도에서 정식 서버 전투 카드로 이동할 수 있습니다. 서버 최고 별점·최고 턴 표시와 기기 기록 이관은 아직 구현하지 않았습니다. 기기 별점을 서버 보상으로 바꾸지 않습니다.

## 검증 기준

- 완료 한 회차로 전투권 2장이 한 번만 지급되고, 동시 청구에도 두 배가 되지 않습니다. 로컬 PostgreSQL 동시 요청 시험을 통과했습니다.
- 전투 응답이 끊겨 같은 요청 ID로 다시 확인해도 훈련권·조각·경험이 중복 차감·지급되지 않습니다.
- 로그아웃·다른 계정 로그인·앱 재설치·백업 가져오기 후에도 계정 보상과 기기 기록이 서로 섞이지 않습니다.
- 화면 테스트에서 320dp·큰 글씨 배치를 확인했습니다. 플립4 실제 계정에서 동기화된 완료 2건으로 4장을 받고, 같은 청구를 다시 해도 0장인지, 서버 전투 1회에 1장이 차감되는지 확인했습니다.
- 플립4 지도에서 기기 전투 클리어 3/3과 계정 정식 첫 승리 3/3, 각 장소의 별점·지급 조각을 따로 표시하는지 확인했습니다.
