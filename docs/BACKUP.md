# 기록 백업과 가져오기

현재 백업 형식은 버전 3이며 별도 할 일의 예정 날짜·시각·완료 날짜·반복 규칙·회차별 완료·쉬기·미루기·중요도·태그·목표 연결·로드맵 행동 연결·작은 단계·보관 상태·알림 선택, 날짜별 메모와 로컬 훈련 게임 자료도 포함합니다. 예전 파일에 예정 날짜·반복·중요도·태그·목표 연결·로드맵 행동 연결·작은 단계·보관·알림 필드가 없어도 가져옵니다. 알림 필드가 없으면 꺼진 상태, 로드맵 행동 연결 필드가 없으면 일반 할 일로 읽습니다. 조용한 시간은 기기 설정이므로 백업에 포함되지 않습니다. 버전 1·2 파일도 계속 가져올 수 있습니다. 할 일·메모는 계정 화면에서 수동 동기화할 수 있지만, 로컬 훈련 게임과 목표·실천 기록은 현재 설치본의 계정 동기화 대상이 아닙니다.

로컬 게임 백업에는 [보상 지급 원장](REWARD_RULES.md), 장소별 전투 별점·최고 턴, 신수별 레벨·전투 경험도 포함합니다. 이전 백업의 할 일 지급 ID는 지급 시각 미상으로 옮기며 훈련권을 다시 주지 않습니다. 첫 장소 전투 승리 기록이 있는 옛 백업에 확정 동료가 없다면 가져올 때 한 번만 추가합니다. 이전 자료에 신수 전투 경험이 없으면 0으로 읽습니다.

앱의 **기록 탭 → 기록 백업·가져오기**에서 목표·실천·쉼 기록과 별도 할 일·메모·로컬 훈련 게임을 JSON 파일로 내보낼 수 있습니다. Android에서는 시스템 파일 저장 창에서 위치를 선택합니다. 웹에서는 브라우저의 다운로드 기능을 사용합니다. 로컬 Chrome에서 JSON 다운로드와 다른 브라우저 저장 공간으로 가져오기를 확인했습니다.

백업 파일에는 목표 문구, 날짜별 실천 강도와 새 기록의 당시 행동 문구, 할 일과 완료 날짜, 날짜별 메모, 로드맵, 보관한 목표, 대표 신수 이름과 테마, 로컬 게임의 보유 신수·발견 종·스쿼드·진행 중 훈련·훈련 완료 횟수·남은 훈련 횟수·훈련 횟수를 지급한 할 일 ID·숲길 지도 클리어 수가 들어 있습니다. 이전 백업처럼 훈련 횟수 필드가 없는 게임 자료는 잔여 0회로 복원합니다. 지도 클리어 필드가 없는 이전 자료는 당시 훈련 귀환 횟수에 맞춰 기존에 열려 있던 장소를 클리어한 것으로 처리합니다. 정식 서버 파견과 뽑기 자료, 로그인 토큰이나 서버 비밀키는 포함되지 않습니다. 파일 내용은 암호화하지 않으므로 Android에서는 저장 위치를 직접 선택하고, 웹에서는 브라우저의 다운로드 위치를 확인해 파일을 관리해 주세요.

## 가져오기 규칙

1. `.json` 파일을 선택하면 앱이 형식과 목표별 기록을 검사한 뒤 가져올 개수를 보여줍니다. 크기 제한은 2 MiB입니다. 주간 기준·가능 시간·목표 날짜가 올바르지 않거나 한 날짜에 실천과 쉼이 함께 있으면 기존 기록을 변경하지 않고 거부합니다.
2. 현재 목표는 지우지 않습니다. ID와 내용이 완전히 같은 목표는 건너뛰고, 같은 ID에 다른 기록이 있으면 가져온 쪽을 새 ID의 **보관본**으로 남깁니다.
3. 가져온 진행 목표 때문에 활성 목표가 5개를 넘으면 초과 목표를 보관본으로 남깁니다. 사용자가 자리를 만든 뒤 보관본을 다시 시작할 수 있습니다.
4. 빈 기기에 가져올 때만 신수 이름과 테마를 복원합니다. 이미 목표가 있는 기기에서는 현재 이름과 테마를 유지합니다.
5. 계정 동기화를 설정한 기기라면 가져온 새 목표가 다음 수동 동기화 때 연결된 계정에 올라갈 수 있습니다. 충돌 보관본은 자동 전송하지 않습니다.
6. 할 일·메모는 ID와 내용이 같으면 중복 추가하지 않습니다. 같은 ID에 다른 내용이 있으면 새 ID로 가져와 양쪽 기록을 유지합니다.
7. 로컬 게임은 아직 시작하지 않은 기기에서만 복원합니다. 이미 시작 동료가 있는 기기에서는 기존 게임 편성과 훈련 기록을 유지합니다. 서버 게임 자료는 이 파일로 복원하지 않습니다.

백업 파일은 자동으로 만들어지지 않습니다. 앱 데이터를 지우거나 기기를 바꾸기 전에 파일을 내보내고, 새 기기에서 가져오기를 실행해야 합니다. Android에서는 내보내기를 누른 뒤 시스템 파일 저장 창에서 위치를 선택합니다. Galaxy Z Flip4의 Downloads에 파일을 저장하고 다시 가져오는 흐름을 확인했습니다. 기존 목표 1개는 같은 기록으로 인식되어 중복 추가되지 않았고, 잘못된 형식의 파일은 오류를 표시했습니다. 웹에서는 할 일 1개를 담은 버전 3 JSON을 내려받아 새 브라우저 저장 공간에 가져오고 홈에서 복원된 항목을 확인했습니다. 헤드리스 Chrome이 운영체제 파일 선택창을 자동 취소해 자동화 도구로 파일 입력에 JSON을 지정했습니다.

파일 기능은 [Flutter file_selector](https://pub.dev/packages/file_selector)와 [share_plus](https://pub.dev/packages/share_plus)를 사용합니다.
