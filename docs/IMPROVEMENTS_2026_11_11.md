# 2026-11-11 자율 개선

사용자 요청: 한 시간 동안 참고 제품과 현재 프로젝트를 살펴보고 필요한 개선과 기능을 직접 선정해 구현한다.

## 선정한 방향

- Habitica에서 참고한 현실 행동→성장 연결은 이미 훈련권과 대표 신수 XP에 반영되어 있다. 이번에는 처음 할 일을 적을 때의 부담을 줄이고, 보상을 받은 근거를 다시 찾기 쉽게 만든다.
- 미니모어맥스에서 참고해 확정했던 작은 실천 원칙을 집중 시작과 주간 돌아보기에 이어 붙인다. 더 오래 하도록 강요하는 연속 기록이나 미완료 벌점을 만들지 않는다.
- 세븐나이츠 리버스의 공식 공략은 적 특성과 보유 동료의 기술을 보고 편성하는 과정을 강조한다. 우리 게임도 단순한 권장 전투력 숫자 외에 빈 전열·미편성 동료와 실제 기술을 설명한다.

## 이번 구현

| 기능 | 진입 위치 | 동작 |
|---|---|---|
| 작은 루틴 예시 | 오늘 → 할 일 추가 | 독서·움직임·한 줄 기록·평일 정리·일요일 돌아보기의 수정 가능한 초안. 고른 뒤 저장해야 추가됨 |
| 반복 날짜 미리 보기 | 새 할 일 → 반복 | 선택한 시작일·요일·간격으로 다음 세 기본 날짜 표시 |
| 내 할 일 재사용 | 할 일의 ⋮ → 새 할 일로 복사 | 제목·반복·태그·단계 초안 재사용. 완료·쉬기·이동·알림 이력을 복제하지 않음 |
| 집중 타이머 | 실천 → 아직 완료하지 않은 목표 | 2·5·10·25분 선택, 멈춤·재개·다시 정하기. 실제 실천 기록은 사용자가 강도를 골라 저장 |
| 목표별 돌아보기 | 기록 → 주간 기록 | 해당 주의 실천·쉼·MINI/MORE/MAX와 현재 주간 기준 비교, 목표 기록 바로가기 |
| 편성 점검 | 모험 → 기기 전투 준비 | 미편성 동료·빈 전열·권장 전투력 안내, 동료 체력·공격·속도·기술·다음 레벨 경험 표시. 시작 버튼은 하단 고정 |
| 계정 원장 찾기 | 게임 → 보상 → 계정 지급·사용 원장 | 검색·기록 종류·최근 7일 필터. 독립된 다섯 서버 조회를 함께 실행 |

## 발견해 고친 문제

- 반복 할 일의 다음 회차를 31일까지만 찾던 제한을 없앴다. 긴 휴식이나 월 단위 반복 예외 뒤에도 다음 날짜를 찾는다.
- 앱을 켜 둔 채 자정을 넘기면 첫 화면 날짜와 회차가 바로 바뀌지 않던 부분에 다음 자정 갱신을 추가했다. 앱 복귀 시에도 타이머 기준을 다시 잡는다.
- 반복 날짜 미리 보기와 주간 복귀일 계산은 달력 날짜를 UTC 자정으로 비교해 일광절약시간의 23·25시간짜리 하루에 영향을 받지 않게 했다.
- 새 주간 집계는 예전 저장본의 쉬움·보통·도전을 MINI·MORE·MAX와 함께 센다.
- 전투 안내의 펼침 항목은 Material 카드 위에서 표시해 배경·터치 효과의 가림 오류를 막는다.
- 계정 원장 새로고침의 `setState` 콜백이 Future를 반환하던 오류를 수정했다. 느린 서버 응답으로 목록이 다시 만들어져도 입력한 검색어가 유지되는 것을 테스트했다.

## 범위와 후속 검토

- 집중 타이머는 최근 집중 한 건의 목표 ID·기간·남은 시간·마감 시각을 로컬에 저장한다. 앱 프로세스가 종료되어도 같은 목표에서 열면 복원한다. 일시 정지는 남은 시간을 고정하고, 실행 중에는 앱을 떠난 시간도 경과한다. 타이머만으로 실천·경험·훈련권을 지급하지 않는다.
- 주간 기준은 목표의 현재 설정이다. 과거 주간 기준 변경 이력을 저장한 것으로 표시하지 않는다.
- 편성 점검은 기기 전투용이다. 계정 정식 전투의 보유·레벨과 혼합하지 않는다.
- 다음 후보: 사용자 맞춤 루틴 초안, 서버 전투의 장소별 최고 기록, 실제 두 기기 동기화 검증. 현재 정한 보상 수치와 게임 진척을 검증하면서 추가한다.

## 다음 개선의 우선순위

최종 검증은 Flutter 테스트 256개·정적 분석·Android 출시 빌드·웹 출시 빌드 통과다. APK 버전 코드는 2003이다. Android 에뮬레이터에서 전체 흐름과 300dp·큰 글씨를 확인했다. [웹 첫 실행 화면](improvements-web.png)도 확인했으며, 브라우저 디버깅을 통한 추가 클릭 자동화는 자동 승인 검토가 정책상 거부했다. 실제 두 플립 기기와 웹의 새 기능 전체 흐름은 추가 점검 범위다.

1. **두 기기에서 기록이 어긋나지 않는지 마무리 검증.** 새 기능 수보다 저장의 신뢰성이 먼저다. 플립6 연결과 플립4 접힌 화면 점검은 기존 U11에 남긴다.
2. **지난 목표 실천의 날짜별 수정.** 현재 목표의 완료하기는 오늘 중심이다. 빠뜨리거나 잘못 남긴 날짜를 고칠 때의 XP 정정과 훈련권 중복 방지 규칙을 먼저 설계한 뒤 달력에 연결한다.
3. **계정 전투의 장소별 최고 기록.** 별점·최고 턴·반복 경험을 모험 지도에서 함께 읽게 하면 재도전의 목적이 분명해진다. 서버 확정 결과를 기준으로 표시한다.
4. **처음 쓰는 사람의 첫 주 흐름.** 목표 하나→MINI 한 번→반복 루틴 하나→첫 동료 편성으로 진행할 때 막히는 지점을 실제 사용으로 찾는다. 안내를 계속 늘리기보다 필요한 순간에 다음 행동을 짚어 준다.
5. **AI 계획의 내용 평가와 배포.** 이미 작성된 계약·평가 기준과 운영 설정을 먼저 검증한다. 수동 목표·루틴만으로도 일상 기록을 충분히 쓸 수 있는 상태를 유지한다.

이 순서는 제안이며, 위 항목의 구현이 끝났다는 뜻은 아니다.
