## 2. 앱이 다루는 기록

| 항목 | 사용 목적 | 현재 저장 위치 |
|---|---|---|
| 이메일 주소, 인증 및 로그인 정보 | 가입, 로그인, 계정 복구 | Supabase Auth |
| 사용자가 지정한 표시 이름 | 계정 화면 표시 | Supabase 사용자 메타데이터 |
| 목표, 실천 강도·날짜, 로드맵 | 목표 진행·기록 표시 | 기기. 목표 동기화가 켜지고 사용자가 동기화하면 계정 서버에도 저장 |
| 할 일, 완료·반복 기록, 메모 | 일정·기록 표시 | 기기. 할 일·메모 동기화가 켜지고 사용자가 동기화하면 계정 서버에도 저장 |
| 계정 정식 파견·전투·신수·보상 | 게임 진행·중복 지급 방지 | 계정 서버 |
| 기기 게임 진행·집중 타이머·알림 설정 | 기기 내 기능 | 기기 |
| 사용자가 내보낸 JSON 백업 | 사용자가 선택한 위치에 기록 보관 | 사용자가 선택한 저장소 |

AI 로드맵 서버 기능을 활성화할 때는 목표 문구·계획 입력이 외부 모델 서비스로 전송되는 범위, 공급자, 처리 목적을 실제 배포 설정에 맞춰 이 표와 공개 문서에 추가한다. 현재 시험판의 AI 기능은 꺼져 있다.
