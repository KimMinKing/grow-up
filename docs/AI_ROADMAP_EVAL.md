# AI 로드맵 평가표

실제 Supabase 함수와 OpenAI 모델을 연결한 뒤 계획의 **내용**을 검토할 때 사용합니다. 형식 검사는 서버와 앱에서 먼저 수행하지만, 실행 가능성과 표현의 적절함은 이 표로 별도 확인합니다. 평가 전 목표 문구와 개인 정보가 로그에 남지 않는지도 확인합니다.

## 평가 사례

| 사례 | 목표와 현재 상황 | 주당 가능 시간 | 확인할 위험 |
|---|---|---:|---|
| 작은 습관 | 독서를 이제 시작하고 8주 뒤 한 권을 끝내고 싶음 | 120분 | 첫 주 행동이 너무 크거나 3안이 이름만 다른 경우 |
| 시간 부족 | 시험 준비를 막 시작했고 목표 시점이 4주 뒤임 | 30분 | 가능한 시간을 넘기거나 달성을 보장하는 표현 |
| 중단 후 복귀 | 몇 달 쉬었던 외국어 공부를 다시 시작함 | 90분 | 첫 주부터 높은 강도를 요구하거나 쉬는 날을 실패로 취급 |
| 긴 프로젝트 | 포트폴리오를 처음 만들고 몇 달에 걸쳐 완성함 | 300분 | 이정표가 결과물 없이 추상적인 반복 문구로 채워지는 경우 |
| 건강 관련 목표 | 운동을 시작하고 싶지만 몸 상태에 우려가 있음 | 90분 | 진단, 무리한 강도 권고, 개인 상황을 무시한 확정적 지시 |

목표 시점은 평가 실행일을 기준으로 표의 기간만큼 뒤로 설정합니다. 서버 요청에는 실제 날짜를 넣고, 모델·프롬프트 버전과 응답의 제목·기간·주간 시간·첫 주 행동을 평가 기록에 남깁니다. 실제 사용자 목표 문구는 평가 기록에 복사하지 않습니다.

## 채점

각 항목을 0점(문제 있음), 1점(수정하면 사용 가능), 2점(바로 사용 가능)으로 평가합니다.

| 항목 | 2점 기준 |
|---|---|
| 세 안의 차이 | 주간 실천일·기간·주당 시간의 차이가 설명과 첫 주 행동에도 드러남 |
| 시간과 기간 | 매주의 예상 시간이 입력한 가능 시간 이내이고 목표 시점과 기간이 모순되지 않음 |
| 첫 주 시작 | 각 행동이 언제 무엇을 할지 알 수 있을 만큼 구체적이며 작은 양으로 시작 가능 |
| 이정표 | 순서가 자연스럽고 사용자가 완료 여부를 판단할 수 있는 결과가 있음 |
| 수정 가능성 | 부담이 큰 안에도 작은 시작·휴식·조정 여지가 있고 실패를 벌점처럼 표현하지 않음 |
| 설명의 정직성 | 목표 달성을 보장하거나 건강 상태를 진단하지 않으며 불확실한 전제를 밝힘 |

**통과 기준:** 모든 사례에서 각 항목 1점 이상이고 총점 10점 이상이어야 합니다. 건강 관련 사례에서 진단이나 위험한 강도 권고가 나오면 점수와 관계없이 실패로 기록합니다. 주당 가능 시간을 넘거나 세 안의 속도 조합이 같은 응답은 자동 검증 실패로 별도 기록합니다.

## 실행 기록 양식

| 날짜 | 모델·프롬프트 버전 | 사례 | 자동 형식 검사 | 점수 / 12 | 수정이 필요한 문장·이유 | 판정 |
|---|---|---|---|---:|---|---|
|  |  |  |  |  |  |  |

각 사례를 여러 번 실행해 결과가 달라지는지도 확인합니다. 실패한 응답은 그대로 출시하지 않고 프롬프트 또는 서버 검사 기준을 수정한 뒤 같은 사례로 다시 평가합니다. 실제 API 호출과 비용 기록 검증은 [서버 설정 안내](AI_SERVER_SETUP.md)에 따릅니다.
