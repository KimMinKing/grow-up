# 방해 앱 실행 전 목표 확인 검토

요청한 동작: **카카오톡의 원래 아이콘을 눌러도 전설키우기의 목표가 먼저 보이고, 1시간에 한 번만 개입**한다. 필요한 메시지는 지연 없이 확인할 수 있어야 한다.

[삼성의 모드 및 루틴 설정 안내](https://www.samsung.com/us/support/answer/ANS10002538/)에 따르면 조건이 충족될 때 지정한 동작을 수행하도록 루틴을 설정할 수 있다.

## 결론

현재 앱에서 이 기능을 뺐다. 이전의 홈 화면 대체 바로가기는 원래 카카오톡 아이콘·알림·최근 앱을 통한 진입을 가로채지 못해 원하는 동작이 아니었다.

삼성 `모드 및 루틴`의 `앱 열림` 조건은 대상 앱이 **이미 열린 뒤** 실행된다. 카카오톡을 열 때마다 전설키우기를 띄우는 방식은 메시지 확인을 방해할 수 있고, 전설키우기에서 카카오톡으로 다시 돌아갈 때 반복 트리거될 수 있다. 휴대폰의 해당 루틴에서 1시간 간격 제한과 예외 처리가 가능한지는 실기기에서 확인할 수 있지만, 선행 화면을 보장하는 방법으로 쓰지 않는다.

Android의 사용 기록 이벤트와 접근성 서비스도 앱이 열린 사실을 **이후** 감지한다. 접근성 서비스로 화면을 덮는 방식은 민감한 권한과 명확한 사용자 동의가 필요하며, 배포 시 Google Play 정책 심사도 필요하다. 이 방식으로도 다른 앱이 열리기 전의 완전한 가로채기를 보장하기 어렵다. [Android 사용 이벤트](https://developer.android.com/reference/android/app/usage/UsageEvents.Event), [백그라운드 화면 실행 제한](https://developer.android.com/guide/components/activities/secure-bal), [접근성 서비스 정책](https://support.google.com/googleplay/android-developer/answer/10964491).

나중에 다시 검토한다면 개입 간격을 최소 1시간으로 제한하고, 전화·메신저 긴급 확인은 즉시 통과하게 하며, 하루 개입 횟수와 조용한 시간을 사용자가 직접 정하도록 한다. 우선은 목표를 자주 보게 하는 부담 낮은 방법(홈 화면 위젯, 선택형 알림, 오늘의 MINI를 한눈에 보는 화면)을 검토한다.
