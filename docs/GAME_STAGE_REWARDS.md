# 첫 숲길 서버 전투와 보상

## 현재 동작

로그인한 사용자는 게임의 **정식 파견 → 정식 숲길 전투**에서 서버 편성으로 첫 지역 세 장소에 도전할 수 있습니다. 서버가 보유 신수·편성·레벨을 읽어 전투 시작 시 고정하고, 서버 함수가 전투를 계산합니다. 첫 승리에는 배지와 뽑기 조각을 한 번 지급합니다. 같은 장소의 반복 승리에는 조각이 없습니다. 서버 전투 경험은 장소별로 하루 5승까지 편성 신수에 1·2·3씩 지급하며 최고 Lv 6입니다. 서버 도전은 현재 한국 날짜로 하루 15회까지입니다. 정식 전투 카드에서 오늘 도전 횟수와 장소별 경험 획득 횟수를 볼 수 있습니다.

기기 안의 훈련·지도·전투는 로그인 없이도 플레이할 수 있는 **별도 진행 기록**입니다. 기기 지도에서 얻은 별·첫 동료·전투 경험은 서버 보상 증빙이 아니며 서버에 복사하지 않습니다. 지도에는 계정의 정식 첫 승리와 지급 조각을 기기 별점과 나란히 표시합니다. 정식 전투는 별도 서버 전투권 1장을 사용합니다. [할 일 완료로 전투권 받는 방법](GAME_TASK_BATTLE_INTEGRATION.md)

| 장소 | 서버 배지 ID | 첫 승리 조각 | 재승리 조각 |
|---|---|---:|---:|
| 이끼 문턱 | `first_footprint` | 1 | 0 |
| 반딧불이 오솔길 | `forest_lantern` | 1 | 0 |
| 새벽 전망대 | `forest_dawn` | 2 | 0 |
| 강가 입구 | `river_entry` | 0 | 0 |
| 물안개 여울 | `river_crossing` | 0 | 0 |
| 달빛 나루 | `river_ferry` | 0 | 0 |

첫 장소의 첫 승리에서는 시작 신수와 다른 종의 서버 동료 한 마리도 받습니다. 보유 한도 20마리가 이미 찼다면 동료는 추가하지 않고 조각과 배지는 지급합니다. 새 서버 동료는 정식 파견 스쿼드에서 직접 편성합니다.

안개 강가에서는 숲길 보스 첫 승리 후 강가 입구가 열리고 각 장소의 첫 승리가 다음 장소를 엽니다. 첫 승리는 서버 배지와 전적을 한 번 기록하지만 뽑기 조각은 지급하지 않습니다. 물안개 여울 첫 승리에서는 보유 20마리 미만인 계정에 레벨 3 자갈도롱뇽 한 마리를 지급합니다. [강가 진행 규칙](SECOND_REGION_PLAN.md)

## 지급과 재시도 방식

[`20261107000000_game_battle_attempts.sql`](../supabase/migrations/20261107000000_game_battle_attempts.sql)은 서버 편성의 5칸 스냅샷, 결과 상태, 전투 경험을 저장합니다. 로그인 계정만 `begin_game_forest_battle`을 호출할 수 있고, 이 함수는 계정별 잠금·앞 장소 승리·일일 횟수·중복 요청을 검사합니다. 앱에서 보낸 승패·레벨·편성은 받지 않습니다. 서버의 [`verify-forest-battle`](../supabase/functions/verify-forest-battle/index.ts) 함수가 스냅샷을 [`battle_engine.mjs`](../supabase/functions/verify-forest-battle/battle_engine.mjs)로 계산한 뒤 서버 역할로 `finish_game_forest_battle`을 호출합니다. 이 한 트랜잭션이 증빙·첫 승리 지급·전투 경험·첫 동료를 확정합니다.

`game_stage_first_clears`의 계정·장소 기본 키와 `game_verified_battles`의 전투 참조가 중복 지급을 막습니다. 첫 승리 지급 함수는 서버 역할에만 허용되고, 증빙 트리거는 계정·장소·승리·별점이 일치하지 않으면 지급을 거부합니다. 앱은 전투 요청 ID를 기기에 보관해 네트워크 응답이 끊기면 같은 ID로 결과를 다시 확인합니다. 완료되지 않은 시도는 같은 ID로 재개할 수 있습니다. [`20261118000000_game_battle_retry_companion.sql`](../supabase/migrations/20261118000000_game_battle_retry_companion.sql)은 전투 중 받은 신수 종을 같은 시도에 기록하고, Edge 함수는 완료된 요청을 다시 조회할 때도 합류 정보를 돌려줍니다. 다른 기기에서 새 요청을 시작하면 5분이 지난 미완료 시도는 만료되고 사용한 전투권을 돌려줍니다. 만료·패배에는 조각을 주지 않습니다.

## 검증과 남은 작업

- 로컬 PostgreSQL 16에서 마이그레이션 9개, 계정 격리·권한·선행 장소·중복 요청·성장·첫 동료·동시 전투 완료·전투권 동시 청구를 시험했습니다. 순수 서버 전투 계산은 Dart 엔진의 822개 편성·레벨 벡터와 일치합니다. Edge 함수는 인증 없는 호출을 401로 거부합니다.
- 2026-11-07 실제 `mpj` 프로젝트에 DB 마이그레이션과 Edge 함수를 적용했습니다. Galaxy Z Flip4 로그인 계정에서 첫 장소 승리→동료와 조각 1개, 둘째 장소 승리→조각 2개, 보스 첫 패배→보상 없음, 반복 전투로 Lv 4 성장→보스 승리→첫 승리 3/3·조각 4개를 확인했습니다.
- 두 계정의 실서비스 격리, 두 기기의 동시 요청, 네트워크 단절 후 동일 ID 재시도, 20마리 한도는 아직 실기기에서 확인하지 않았습니다. 정식 전투를 기기 지도와 합치는 작업이 남았습니다. 정식 전투 결과는 현재 간단한 결과 표시이며 기기 전투의 애니메이션을 아직 재생하지 않습니다.
