# 현실 행동과 게임 보상 규칙

2026-11-18 기준 경제 규칙입니다. [2주 경제 시뮬레이션](REWARD_ECONOMY.md)으로 계정 정식 전투권 상한도 검토했습니다. 실제 사용량을 측정한 뒤 수치를 다시 조정합니다.

| 행동 | 훈련권 | 신수 XP | 모험 재료 | 지급 단위 |
|---|---:|---:|---:|---|
| 일회성 할 일 완료 | 2 | 0 | 0 | 할 일 ID당 최초 1회 |
| 반복 루틴 완료 | 2 | 0 | 0 | 할 일 ID와 날짜당 최초 1회 |
| 목표 MINI 실천 | 1 | 10 | 0 | 목표 ID와 날짜당 최초 1회 |
| 목표 MORE 실천 | 2 | 20 | 0 | 목표 ID와 날짜당 최초 1회 |
| 목표 MAX 실천 | 3 | 30 | 0 | 목표 ID와 날짜당 최초 1회 |
| 로드맵 단계 완료 | 0 | 0 | 0 | 단계 자체는 별도 보상이 없음 |

하루에 **별도 할 일·반복 회차 합계 5개**까지만 훈련권을 지급합니다. 초과한 완료도 기록과 원장에는 남지만 훈련권은 0회입니다. 목표 실천은 이 상한에 포함하지 않습니다. 작은 하위 단계, 로드맵 연결 행동에는 별도 보상이 없습니다. 과하게 잘게 쪼갠 체크로 훈련권을 무한히 만드는 일을 막으면서, 하루 1~5개의 실제 할 일에는 동일한 보상을 줍니다. 같은 날 뒤늦게 게임을 열어도 완료 날짜를 기준으로 상한을 적용합니다.

게임을 늦게 열어도 최근 14일 동안 완료한 행동까지 훈련권을 받을 수 있습니다. 그보다 오래된 완료는 기록과 XP 계산에 남기되 훈련권은 0회로 원장에 표시합니다. 미래 날짜 기록은 그 날짜가 될 때까지 지급하지 않습니다. 이 기간은 게임을 오래 쉬었다 돌아온 사람의 과거 기록을 한꺼번에 훈련권으로 바꾸지 않기 위한 임시 규칙입니다.

로드맵에서 오늘 행동으로 가져온 할 일은 목표 실천과 같은 완료를 공유합니다. 이 할 일에는 일반 할 일 훈련권을 추가 지급하지 않습니다. 하위 단계 체크도 별도 보상을 지급하지 않습니다. 로드맵 단계 완료는 결과를 기록하는 표시이며, 그 과정의 MINI·MORE·MAX 실천으로 보상받습니다. 기기 로드맵 완료 자체는 계정 정식 게임의 재료를 지급하지 않습니다. 계정 정식 파견과 숲길 첫 승리 보상은 서버가 소유권과 중복 지급을 검증해 발행합니다.

목표 XP는 목표의 날짜별 실천 기록으로 매번 계산합니다. 완료 강도를 바꾸거나 취소하면 XP도 바뀝니다. 훈련권은 지급 원장에 한번 기록되면 취소·재완료 때 다시 지급하지 않으며, 이미 사용한 훈련을 되돌리지 않습니다. 이 규칙은 B03에서 화면 설명과 함께 재검토합니다. 같은 날짜의 MINI를 MAX로 올려도 훈련권 1회가 3회로 증가하지 않습니다.

게임을 열면 아직 지급하지 않은 완료를 찾아 훈련권과 원장 기록을 한 번에 로컬 저장합니다. 원장에는 완료 식별자, 행동 종류, 훈련권 수량, 당시 XP, 지급 시각이 들어갑니다. 예전 게임 저장의 `creditedTaskIds`는 이미 지급된 훈련권으로 인정하며 원장에는 지급 시각 미상(`1970-01-01`)으로 옮깁니다. JSON 백업에도 원장이 포함됩니다. 계정 간 원장 동기화와 두 기기 동시 완료의 서버 중복 방지는 아직 없으므로 B02는 진행 중입니다.

## 계정 정식 게임의 별도 보상

| 행동 | 계정 보상·소모 | 제한 |
|---|---|---|
| 동기화한 별도 할 일 완료 청구 | 정식 전투권 +2장 | 최근 30일 기록, 할 일 ID·완료 날짜당 1회, 잔액 30장 상한(29장부터 청구 대기) |
| 정식 전투 시작 | 정식 전투권 -1장 | 같은 전투 요청 재시도는 중복 차감하지 않음 |
| 정식 파견 귀환 | 뽑기 조각 +1개 | 10분 파견, 한국 날짜로 하루 3회, 별도 파견권 없음 |
| 숲길 장소별 정식 첫 승리 | 이끼 문턱 +1개 · 반딧불이 오솔길 +1개 · 새벽 전망대 +2개 | 계정별 장소당 최초 1회 |
| 강가 장소별 정식 첫 승리 | 자갈도롱뇽 동료 또는 성장 경험치 | 계정별 장소당 최초 1회, 보유 동료 20마리 상한 |
| 무료 뽑기 | 뽑기 조각 -3개 | 서버가 결과와 차감을 한 번에 확정 |

기기 훈련권과 정식 전투권은 서로 옮기거나 합칠 수 없습니다. 기기 이야기 전투는 훈련권 1회를 쓰며 서버 조각을 지급하지 않습니다. `보상` 탭에는 두 잔액을 따로 보여줍니다. [2주 경제 시뮬레이션](REWARD_ECONOMY.md) 결과, 현재는 정식 파견에 별도 입장권을 추가하지 않습니다. 실제 파견 빈도와 조각 사용량을 확인한 뒤 재검토합니다.
