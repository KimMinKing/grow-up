# 앱 이름 후보

2026-10-30. 사용자가 제안한 **「전설키우기」**를 시험용 앱 표시 이름으로 적용했습니다. 내가 실천하면서 전설이 된다는 뜻을 담습니다. 정식 이름은 사용 후 확정합니다.

| 후보 | 느낌 | 고려할 점 |
|---|---|---|
| **하루각성** | 오늘 한 걸음과 캐릭터 각성을 함께 담음. 현재 추천 | 게임 분위기가 강한 편 |
| **동행록** | 나와 신수가 함께 걸으며 기록한다는 느낌 | 성장·퀘스트 기능이 이름만으로 드러나지는 않음 |
| **작은각성** | 작은 습관에서 시작해 성장한다는 메시지 | 역동적인 게임 이름보다는 차분함 |
| **각성일지** | 상태창과 실제 성장 기록이 연상됨 | 일기 앱처럼 보일 수 있음 |
| **전설키우기** | 내가 꾸준히 성장해 전설이 된다는 느낌 | 신수 수집 게임으로만 보이지 않도록 성장 기능을 먼저 보여줘야 함 |

빠른 웹 검색에서는 정확히 같은 이름의 대표적인 습관 앱을 확인하지 못했습니다. 이는 앱스토어·상표·도메인 사용 가능 여부를 보증하지 않습니다. 최종 후보를 고르면 정식 출시 전에 별도로 확인합니다. 게임이나 유명 작품의 고유 명칭·이미지를 앱 이름에 직접 사용하지 않습니다.
