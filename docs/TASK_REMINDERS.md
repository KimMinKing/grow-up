# 할 일 알림

Android 앱에서 **오늘 → 할 일 추가/수정 → 날짜와 시간 설정 → 예정 시각 알림**을 켜면 해당 할 일의 알림을 예약합니다. 반복 할 일은 날짜 대신 반복 규칙과 시간을 지정할 수 있습니다. 처음 켤 때 Android 알림 권한을 요청합니다. 권한을 거부하면 알림 스위치는 꺼진 채로 남으며 할 일 자체는 저장할 수 있습니다. 나중에 기기 설정에서 권한을 허용한 뒤 할 일의 알림 스위치를 다시 켜면 예약합니다.

**오늘 → 알림과 조용한 시간**에서 야간 등 알림을 피할 시간을 설정할 수 있습니다. 기본값은 꺼짐, 22:00~08:00입니다. 사용하면 그 시간에 해당하는 알림을 종료 시각으로 미룹니다. 반복 일정 두 회차의 알림이 같은 시각에 겹치면 한 번만 보냅니다. 완료·쉬기·미루기·삭제·보관에 따라 앱이 예약을 다시 계산합니다.

예약은 기기에서 처리하므로 앱을 닫아도 남습니다. Android 재부팅 후에는 `flutter_local_notifications`의 부팅 수신기가 남은 예약을 다시 등록하도록 설정했습니다. Android의 배터리·알림 정책 때문에 실제 도착 시각은 달라질 수 있습니다. 정확한 분 단위 알림 권한은 요구하지 않으며 `inexactAllowWhileIdle`을 사용합니다. 현재 예약 범위는 앞으로 60일, 최대 100건입니다. 오래 앱을 열지 않으면 그 이후 반복 알림은 추가되지 않습니다. 앱을 다시 열면 60일 예약을 갱신합니다. 웹에서는 예약 알림을 제공하지 않습니다.

알림을 켠 할 일은 JSON 백업에 포함됩니다. 조용한 시간은 현재 기기의 설정이어서 백업에 포함되지 않습니다. 다른 기기에 가져온 뒤 앱을 열고 Android 알림 권한과 조용한 시간을 확인해야 합니다.

## 검증 상태

- 알림 시각, 반복 완료·미룸, 조용한 시간, 오래된 JSON 기본값, 백업 왕복과 320dp·200% 글씨 설정 화면을 자동 테스트로 확인했습니다.
- Android 디버그·x64 출시 APK 빌드와 Galaxy Z Flip4 설치, 에뮬레이터 화면 표시, 설치된 권한·부팅 수신기 선언을 확인했습니다.
- Android 에뮬레이터에서 권한 요청을 거부했을 때 알림 스위치가 꺼진 채 유지되는 것을 직접 확인했습니다. 권한을 허용한 뒤 오늘 시각 알림을 켜고 저장하자 Android 알람 서비스에 `ScheduledNotificationReceiver`의 예약이 등록됐습니다. 앱 프로세스를 종료한 뒤에도 알림이 도착했고 [알림창 화면](task-reminder-emulator.png)을 확인했습니다. 에뮬레이터를 재부팅한 뒤에도 남은 예약이 다시 등록되어 실제로 도착했습니다. [재부팅 후 알림창](task-reminder-reboot-emulator.png)도 확인했습니다. 예정 시각은 03:50이었고 Android의 느슨한 예약 정책에 따라 03:52에 도착했습니다. 이후 새 시각으로 예약했다가 할 일 알림을 끄니 Android 알람 기록에 취소가 남고 예정 알람 목록에서 사라졌습니다. 시험용 할 일도 삭제했습니다.
- 2026-11-06 Galaxy Z Flip4에서 `POST_NOTIFICATIONS`가 꺼진 상태를 확인한 뒤 시험용 할 일의 알림 스위치로 Android 권한 요청을 열고 허용했습니다. 오늘 21:30으로 예약하자 Android 알람 서비스에 `ScheduledNotificationReceiver`의 `RTC_WAKEUP` 예약이 생겼습니다. 앱을 홈으로 내려놓은 상태에서 21:31 실제 알림창에 앱 아이콘·`할 일 예정`·시험 제목이 표시됐고 알림을 눌러 앱이 열렸습니다. 시험용 할 일은 삭제했습니다. 알림의 예정 시각과 실제 표시 사이에는 약 1분 차이가 있었습니다.
- 2026-11-07 알림의 할 일 ID를 앱으로 전달해, 탭하면 오늘 화면에서 해당 할 일의 제목·날짜·시간·완료 상태를 보여주고 바로 수정할 수 있게 했습니다. 이미 삭제된 할 일이면 안내 메시지를 보여줍니다. 위젯 테스트에서 앱을 새로 여는 경우와 게임 화면에서 돌아오는 경우를 확인했습니다. Galaxy Z Flip4에서 03:32로 예약한 시험 알림이 03:33에 도착했고, 알림을 눌러 해당 할 일 정보 창이 열리는 것을 확인했습니다. 시험 할 일은 삭제했습니다. 실기기에서 앱 프로세스 종료·기기 재부팅 뒤 알림 도착은 아직 확인하지 못했으므로 A10은 진행 중입니다.

구현에 사용한 [flutter_local_notifications 설치 안내](https://pub.dev/packages/flutter_local_notifications), [Android 14 알람 권한 변경](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms)을 참고합니다.
